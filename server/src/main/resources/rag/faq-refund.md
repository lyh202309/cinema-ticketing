# 退票与取消

<!-- 同步自 service/impl/OrderServiceImpl.java 的 refund() 与 cancel() -->

## 已支付的订单怎么退票？能退钱吗？
在「我的订单」里找到这笔订单，点退票就能退款。目前只支持整单退票，不支持只退其中几张。
退票不收取手续费，也没有时间限制，开场前后都可以申请。
退票成功后座位会立刻释放回可售状态，可以再买给别人。

## 待支付的订单怎么取消？
可以直接在订单页点取消，也可以什么都不做等它自动超时。
两种方式效果一样，座位都会释放回可售状态。

## 能改签吗？想换一场看
目前没有改签功能，不能直接把订单换到另一个场次。
如果想换一场，可以先退掉原来的订单，再重新选座购买。
热门场次重新购买时可能还要再抢一次票。

## 退票之后钱什么时候到账？
本系统是模拟支付环境，付款时不会真的扣款，
退票后订单状态会变成「已退款」，不涉及真实的资金流转和到账时间。

## 订单有哪些状态？
待支付、已支付、已取消、已退款四种。
待支付的订单可以付款或取消；已支付的订单可以退票；
已取消和已退款是最终状态，不能再做任何操作。
