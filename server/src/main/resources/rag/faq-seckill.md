# 热门场次与抢票

<!-- 同步自 service/impl/SeckillServiceImpl.java 与 controller/SeckillController.java -->

## 为什么有的场次要先抢票？
热门场次想看的人多，为了分散瞬时压力，需要先抢票才能进入座位图选座。
普通场次不需要这一步，直接选座购票就可以。

## 抢票时提示「当前人数过多，服务器繁忙，请稍后重试」怎么办？
说明这一刻抢票的人比较多，稍等几秒再点一次就好。
连续快速点击反而容易触发限制，建议放慢一点节奏重试。

## 为什么提示「该场次无需抢票，可直接购票」？
说明这个场次不是热门场次，不需要抢票，直接进座位图选座就可以了。
这不是错误提示，按提示直接购票即可。

## 抢票一直失败是不是没票了？
不一定。提示「人数过多」是瞬时拥挤，和场次还有没有剩余座位是两回事。
要先抢到票进到座位图里，才能看到这个场次真实的剩余座位情况。
所以抢票失败时先多试几次，别急着判断已经卖完。
