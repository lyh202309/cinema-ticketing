# 选座与座位图

## 怎么选座？
进入场次后打开座位图，点选想要的座位，可以一次多选，最多 5 个，然后点锁座下单。
座位图上已经被人占用的座位不能选，选中的座位会高亮显示。
选座本身没有别的限制，也不要求必须选连座；唯一的限制就是一次最多选 5 个座位。

## 想选的座位显示被占了怎么办？
说明这个座位刚被其他人买走或者正在被锁定。
换一个座位即可；如果发现可选的座位已经很少，说明这场比较热门，建议尽快下单，
否则看中的座位可能又被别人选走。

## 为什么座位图打不开？
热门场次需要先抢票才能进入座位图，没抢到票时访问会提示不能查看该场次座位。
普通场次如果打不开，请确认这个场次是不是还没开售，或者已经过了售票截止时间。

## 锁座之后座位还会被别人抢走吗？
不会。锁座成功的那一刻座位就为你保留了，5 分钟内其他人选不了同一个座位。
但如果 5 分钟内没有完成支付，订单会自动取消，座位重新释放回可售状态，
这时候别人就可以选了。
