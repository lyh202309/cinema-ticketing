# 支付与订单超时

<!-- 同步自 config/RabbitMQConfig.java 的 ORDER_TIMEOUT_MS = 300_000 与 service/impl/OrderServiceImpl.java 的 pay() -->

## 支持哪些支付方式？
当前是模拟支付环境，在支付页点确认就会直接支付成功，不会真的扣款，
也不需要绑定微信、支付宝或银行卡。
所以演示和试用时随便点都可以，不会产生真实消费。

## 锁座之后多久要付款？
5 分钟。锁座下单后座位为你保留 5 分钟，超时订单会自动取消，座位释放回可售状态。
如果还想买，需要重新选座下单，前面的订单不会自动恢复。

## 订单超时被取消了怎么办？
重新选一次座位下单就行，流程和第一次完全一样。
如果这个场次比较热门，可能需要在选座前重新抢一次票。

## 支付失败怎么办？
模拟支付点确认即成功，正常情况下不会失败。
如果页面提示异常，刷新后到「我的订单」看看订单状态；
状态还是待支付的话，可以再点一次支付按钮。
