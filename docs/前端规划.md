# 电影院订票系统 · 前端规划

> 技术栈：**Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios**
> 设计原则：后端是重点（并发/秒杀/缓存/AI），前端"够用、能演示完整购票链路"即可，不做过度花哨。
> 对接：《接口文档.md》；架构决策见《设计文档.md》。

## 2. 路由与页面（+ 登录守卫分组）

| 路由 | 页面 | 公开/需登录 | 说明 |
|---|---|---|---|
| `/login` | Login | 公开 | 验证码/密码登录 |
| `/` | Home | 公开 | 电影列表（首页，按类型筛） |
| `/movie/:id` | MovieDetail | 公开 | 电影详情 + 该片场次入口 |
| `/cinema/:id` | CinemaDetail | 公开 | 影院详情 + 影厅 + 该影院场次 |
| `/session/:id` | SessionDetail | **需登录** | 场次购票入口：普通→选座；热门→"抢票"按钮 |
| `/seckill/:id` | SeatSelect | **需登录** | 选座页（座位图 + 提交锁座） |
| `/pay/:orderId` | Pay | **需登录** | 支付页（5min 倒计时） |
| `/orders` | Orders | **需登录** | 我的订单列表/详情/退票 |
| `/chat` | Chat | **需登录** | AI 对话助手（SSE） |

- 路由守卫：白名单 = `/login` + 公开浏览页（Home/Movie/Cinema）；其余未登录 → 跳 `/login`
- 登录态存 Pinia + localStorage（token 持久化，刷新不丢）

## 3. 关键交互与组件

### 3.1 `SeatMap.vue`（选座页核心）
- props：`rows / cols / seats[][]`
- 渲染网格，三态颜色：可售(可点) / 已占(灰禁点) / 已选(高亮)
- 交互：多选 + 上限（如 5 座）；提交后调 `POST /lock`
- 锁座失败（座位被抢）→ 重新拉座位图 + 提示

### 3.2 `CountDown.vue`（支付倒计时）
- 5min 倒计时展示；归零提示"订单可能已超时，请刷新查看状态"
- 支付成功 / 取消 / 超时的跳转分支处理干净

### 3.3 抢票按钮（热门场次）
- `POST /qualify` 三分支：
  - `0` 抢到 → 跳 `/seckill/:id`
  - `1` → 提示"当前人数过多，服务器繁忙，请稍后重试"（可重试）
  - `2` → 提示"请勿重复操作"，仍可进选座页
- 页面不出现"资格/名额"字样

### 3.4 AI 聊天页（SSE）
- POST + **fetch 流式读取**（不能用 EventSource，它是 GET；需带 token）
- 打字机渲染 + 会话列表侧栏（新建/历史/删除）
- 识别 LLM 输出的 ASCII 座位图代码块 → 用代码块样式展示

## 4. 关键实现点

### 4.1 axios 封装 `utils/request.js`
- 请求拦截：`authorization: Bearer token`（从 Pinia/localStorage 取）
- 响应拦截：`code===1` 返回 data；`code===0` toast msg；**403** → 提示"非法操作"并跳登录

### 4.2 页面 ↔ 接口映射
| 页面 | 接口 |
|---|---|
| Home | `GET /movie` |
| MovieDetail | `GET /movie/{id}` + `GET /session?movieId=` |
| CinemaDetail | `GET /cinema/{id}` + `GET /session?cinemaId=` |
| SessionDetail | `GET /session/{id}` + （热门）`POST /seckill/qualify/{id}` |
| SeatSelect | `GET /seckill/seatmap/{id}` + `POST /seckill/lock` |
| Pay | `POST /order/{orderId}/pay` / `POST /order/{orderId}/cancel` |
| Orders | `GET /order/my` + `GET /order/{id}` + `POST /order/{id}/refund` |
| Chat | `GET/POST /chat/conversations` + `POST /chat/conversations/{id}/chat`(SSE) |

## 5. 开发顺序建议（前端）

1. 搭 Vite 工程 + 依赖 + axios/路由/Pinia 骨架
2. Login + 首页(电影) + 详情页（浏览链路，最快看到东西）
3. 场次 → 选座页（SeatMap）→ 提交锁座
4. 支付页（倒计时）+ 我的订单 + 退票
5. 抢票按钮（热门场次）
6. AI 聊天页（SSE）
